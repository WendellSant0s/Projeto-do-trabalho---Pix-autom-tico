# Projeto de trabalho - Pix Automático

Este projeto é uma página interativa em HTML que apresenta de forma visual e educativa como funciona o Pix Automático, com explicações passo a passo, comparativos e elementos dinâmicos.

## Objetivo

Explicar, de maneira clara e didática, o funcionamento do Pix Automático para associados e colaboradores, incluindo:

- contratação do serviço
- autorização no aplicativo
- cobrança automática
- gestão e cancelamento da autorização

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Tailwind CSS via CDN

## Como visualizar o projeto

1. Abra o arquivo `pix_automatico_sicredi (1).html` em um navegador.
2. Ou utilize um servidor local simples, como o VS Code Live Server, se preferir.

## Estrutura do projeto

- `pix_automatico_sicredi (1).html` — página principal com o conteúdo e interações
- `README.md` — documentação do projeto

## Funcionalidades

- navegação por etapas
- barra de progresso
- autoplay para apresentação
- interface responsiva
- explicação visual de cada etapa do fluxo

## Observação

Este projeto foi desenvolvido como material de trabalho e apresentação, com foco em explicação visual e didática do processo de Pix Automático.
